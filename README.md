# Portafolio de Proyectos de Machine Learning e Inteligencia Artificial

¡Hola! Soy Hervin R., un apasionado científico de la computación con un profundo interés en resolver problemas complejos a través de los datos. Este repositorio sirve como mi portafolio profesional, donde documento y comparto una colección de proyectos que demuestran mi experiencia en diversas áreas del Machine Learning y la Inteligencia Artificial.

---

## 🌟 Sobre Este Portafolio

El objetivo de este repositorio es showcasear mi habilidad para abordar problemas de principio a fin: desde el preprocesamiento y análisis exploratorio de datos (EDA), hasta la implementación, entrenamiento y evaluación de modelos complejos. Cada proyecto está contenido en un notebook de Jupyter/Colab, diseñado para ser claro, reproducible y pedagógico.

### 🛠️ Tecnologías y Librerías Utilizadas

A lo largo de estos proyectos, he utilizado un stack tecnológico moderno y estándar en la industria:

*   **Lenguaje:** Python
*   **Análisis y Manipulación de Datos:** Pandas, NumPy
*   **Visualización de Datos:** Matplotlib, Seaborn, Plotly
*   **Machine Learning Clásico:** Scikit-learn (`LinearRegression`, `SVC`, `KMeans`, `PCA`, etc.)
*   **Deep Learning:** TensorFlow, Keras (`Sequential`, `Functional API`, `CNNs`, `RNNs`, `VAEs`)
*   **Aprendizaje por Refuerzo:** Implementaciones con NumPy.

---

## 📂 Estructura de Proyectos

Este portafolio está organizado en carpetas temáticas. Cada carpeta contiene uno o más notebooks relacionados con ese campo del Machine Learning.

| Carpeta | Descripción |
| :--- | :--- |
| **[🧠 Aprendizaje Supervisado](#-aprendizaje-supervisado)** | Modelos que aprenden de datos etiquetados para tareas de clasificación y regresión. |
| **[👁️ Aprendizaje No Supervisado](#️-aprendizaje-no-supervisado)** | Algoritmos que descubren patrones y estructura en datos no etiquetados (Clustering y Reducción de Dimensión). |

## 💻 ¿Cómo Usar este Portafolio?
